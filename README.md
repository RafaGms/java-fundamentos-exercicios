# Java — Fundamentos e Exercícios

Repositório criado para registrar meus estudos e exercícios práticos durante o aprendizado dos fundamentos da linguagem Java.

Os exercícios têm como objetivo praticar conceitos básicos da linguagem e evoluir gradualmente para conteúdos mais avançados.

## 📚 Conteúdos

### Fundamentos

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Métodos
- Arrays
- Orientação a Objetos

## 📝 Exercícios

### 01 — Fundamentos da Linguagem

Exercícios relacionados a:

- Entrada de dados com `Scanner`
- Variáveis
- Tipos de dados
- Operações matemáticas
- Manipulação de strings
- Cálculo de idade
- Cálculo de áreas

## 🛠️ Tecnologias

- Java
- IntelliJ IDEA
- Git
- GitHub

## 📖 Fonte

Exercícios baseados no material de estudos da [Digital Innovation One (DIO)](https://github.com/digitalinnovationone/exercicios-java-basico).

## 🎯 Objetivo

Utilizar este repositório como um registro da minha evolução no aprendizado de Java, praticando os conceitos apresentados durante os estudos e aplicando-os em exercícios práticos.
